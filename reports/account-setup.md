# 계정 개설 체크리스트: 살말테크 (X, 인스타그램)

가입은 휴대폰·이메일 인증 때문에 직접 해 주셔야 합니다. 나머지 값은 모두 준비돼 있습니다.
값의 원본은 `config/accounts.json`, 이미지는 `brand/`에 있습니다.

## 1. 인스타그램 (약 10분)

- [ ] 새 계정 가입. 사용자 이름은 `salmal.tech` → `salmal_tech` → `salkkamalkka.tech` 순으로 시도
- [ ] 이름: `살말테크 | 사기 전에 숫자로`
- [ ] 프로필 사진: `brand/avatar.png`
- [ ] 소개: `config/accounts.json`의 `instagram.bio`를 그대로 복사
- [ ] 링크: `https://starlink.com?referral=RC-DF-16524681-29887-13`
- [ ] 설정 > 계정 유형 > **프로페셔널 계정(크리에이터)**로 전환, 카테고리 `디지털 크리에이터`
  - 예약 게시 도구가 인스타그램에 자동 게시하려면 프로페셔널 계정이 필요합니다.
  - 연결 도구가 요구하면 페이스북 페이지를 하나 만들어 연결합니다.

## 2. X (약 5분)

- [ ] 새 계정 가입. 사용자 이름은 `salmal_tech` → `salmaltech` → `salkkamalkka` 순으로 시도(X는 점을 못 씁니다)
- [ ] 이름: `살말테크`
- [ ] 프로필 사진 `brand/avatar.png`, 헤더 `brand/x-header.png`
- [ ] 소개: `config/accounts.json`의 `x.bio`
- [ ] 위치 `대한민국`, 웹사이트 `https://starlink.com?referral=RC-DF-16524681-29887-13`

## 3. 스레드와 블로그

- [ ] 스레드: 새 인스타그램 계정으로 스레드 프로필 생성. 소개와 링크는 인스타그램과 같게
- [ ] 네이버 블로그: 쓸 네이버 계정을 정해 알려 주세요. 블로그 소개에도 같은 추천 링크 표시를 넣습니다

## 4. 연결 (약 5분)

- [ ] claude.ai 커넥터 설정에서 Metricool 연결 → Metricool에서 계정 연결
  - 연결되면 `config/campaign.json`의 `publisher_connector`에 등록해야 팀이 씁니다.
  - 커넥터가 없는 동안 팀은 `approved`에서 멈춥니다. 브라우저 자동화 같은 다른 경로로 올리지 않습니다.
    그동안은 `content/<id>/final/`의 최종본을 직접 복사해 올리시면 됩니다.
- [ ] 같은 이름의 계정이 이미 있으면 다음 후보로 넘어갑니다.
- [ ] 정한 사용자 이름을 알려 주시면 `config/accounts.json`의 `handle`과 카드 하단 표기를 맞춥니다.

## 5. 첫 게시 순서

모든 게시물은 `reports/approval-*.md`에서 승인한 것만 나갑니다. 같은 채널 게시물은 3시간 이상 띄웁니다.

1. 반값 할인 실구매비(20261118-01): 마감(보도 기준 28일) 때문에 가장 먼저
2. 계정 소개(20261118-07): 01 다음에 올리고 프로필 상단에 고정(재검수 후)
3. 미니 vs 스탠다드(20261118-02): 다음 날

## 하지 않는 것

- 남의 게시판, 댓글, 단톡방에 추천 링크나 게시물 올리기
- 맞팔 품앗이, 팔로워 구매, 자동 팔로우·좋아요, 대량 댓글
- 같은 사람의 여러 계정으로 서로 띄우기
- 스타링크 로고·이름을 넣은 프로필(공식 계정처럼 보이면 사칭 신고 대상)
- 추천 링크가 걸린 게시물, 프로필, 계정 자체의 유료 홍보(팔로워 광고, 프로필 방문 광고 포함)
